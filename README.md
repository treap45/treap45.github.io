# treap45.github.io

Personal blog, built with Jekyll and hosted on GitHub Pages.

## Local preview

```
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.

## Writing a new post

Add a file to `_posts/` named `YYYY-MM-DD-title.md` with front matter:

```
---
layout: post
title: "Post Title"
date: YYYY-MM-DD
---
```
